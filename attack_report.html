Figures

Shadow phase: is there any membership signal?

Two overlaid histograms of dist_from_boundary (how decisive the model was). Orange = pairs the shadow models trained on, blue = pairs they did not. Heavily overlapping shapes with the dashed mean lines only slightly apart means a weak leak; clearly separated shapes would mean a strong one.

Shadow phase: is the gap real, and does it repeat?

Left: the member/non-member gap per feature on a common scale (Cohen's d; roughly 0.2 = small, 0.5 = medium). Bars that keep the same sign and size across K are signal; bars that flip around are noise. The last bar group is the real target, so you can see whether the shadow gap carries over. Right: one dot per shadow model - dots mostly above zero mean the effect repeats.

Validity check: did the target RLM learn the linkage task?

Training vs validation loss for both stages of the target model. If both curves fall and level off, the model learned. A growing gap between them is overfitting, which is what membership inference exploits.

Attack phase: how well does the attack beat guessing?

ROC curves on the real target. The dashed diagonal is random guessing. The further a curve bows toward the top-left, the stronger the attack. The right panel zooms into the low false-positive region, which matters most for privacy (a few confident, correct guesses are the real risk).

Attack phase: do the scores separate members from non-members?

What the attack predicted for the real target's true members (orange) and true non-members (blue). If the two histograms overlap almost completely, the attack cannot tell them apart.

Attack phase: which features does the attack lean on?

How much the attack's AUC drops when each feature is shuffled. Longer bar = more important. Expect dist_from_boundary to dominate if the confidence leak is the main signal.

Limitations

  • The target RLM was retrained from target_train.csv using the notebook's Variant A recipe; if the client supplied a pre-trained target model, results may differ.
  • Shadow models were trained on about half the shadow pool (roughly 20,000 pairs), whereas the target was trained on 32,000 pairs, so the shadow models may not overfit to exactly the same degree as the target.
  • Membership is judged per record pair. Some individual record IDs appear in both target_train and target_test (inside different pairs), so a few 'non-member' pairs contain records the model has seen.
  • The evaluation set is imbalanced (about 80% members), so AUC and TPR at low FPR are more trustworthy than raw accuracy.
  • Only the Variant A architecture (autoencoder + classifier) was attacked.
  • The target answer key is only available in this simulated environment; a real black-box attacker would not have it, so these numbers are an evaluation, not something an attacker could compute.
